## 楼中楼展开不再回顶部

- 原因：`查看更多评论` 是 `<a href="#">`，点击时 hash 被置空触发浏览器默认的「滚回顶部」，与 Vue 重渲染无关（`getCommentList` 只返回数据，不重建 webview）。
- 修法：`@click="loadMoreComments(item)"` → `@click.prevent="loadMoreComments(item)"`，保留滚动位置，新评论插在按钮前、下方内容自然下移。仅改这一行。
- 只加 `.prevent` 仍会回顶部（webview 会自行拦截 `<a href>` 点击），最终方案：链接去掉 `href`（改 `style="cursor: pointer"` 保留可点感）＋ `loadMoreComments` 里记录 `window.scrollY`，`$nextTick` 后用 `window.scrollTo` 还原；还原条件 `scrollTop > 0 && window.scrollY < scrollTop`，避免和浏览器滚动锚定打架。
